ARTIFYANY — PINTEREST GALLERY + SMOOTH STUDIO MOTION
==================================================

WHAT YOU'RE GETTING
- Your 6 uploaded ArtifyAny artworks (not sample images)
- Pinterest-style masonry gallery with mixed card heights
- Smooth entrance animations, hover zoom, subtle floating hero art
- Filter buttons and click-to-expand gallery viewer
- Responsive for desktops, tablets, and phones
- Accessibility: keyboard support and reduced motion preferences
- Free static-site compatible (GitHub Pages, Cloudflare Pages)

HOW TO OPEN
1. RIGHT-CLICK the ZIP file and choose "Extract All".
2. Open the extracted ArtifyAny-Pinterest-Apple-Style folder.
3. Double-click index.html to preview in Chrome.
   IMPORTANT: Do not open it while still inside the ZIP.

HOW TO EDIT
- index.html: words, links, galleries, picture descriptions
- style.css: color palette, typography, layout, effects
- script.js: gallery filters, full-screen viewer, scroll reveals
- images/: the 6 original artworks you supplied

HOW TO ADD ARTWORK
1. Save a photo in images/ (e.g. art-07.jpg).
2. Copy an <article class="art-card ..."> block in index.html.
3. Change the image path, title, category, and alt description.
4. Increase the "All work 06" counter if desired.

HOW TO PUBLISH FOR FREE
1. Create a public GitHub repository, e.g. artifyany-website.
2. Upload the contents of this folder (index.html, style.css,
   script.js, and images/). Do not upload just the ZIP.
3. GitHub repository > Settings > Pages > Deploy from branch > main /root.
4. To connect artifyany.com, add your domain in GitHub Pages settings
   and configure the required A/CNAME DNS records at Wix.
5. Verify DNS and enable Enforce HTTPS when offered.
